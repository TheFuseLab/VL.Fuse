# Planned Features

This folder contains detailed plans and research for features that are planned but not yet implemented.

## Features

| Feature | Status | Description |
|---------|--------|-------------|
| [Delegate Support](delegate-support.md) | Planned | Pass delegates (callable shader functions) as parameters to mixin functions |

## How to Use

Each feature document contains:
- Overview and motivation
- Technical research and analysis
- Implementation plan with code snippets
- Files to modify
- Verification steps
- Challenges and considerations

When ready to implement a feature, refer to the corresponding document for the detailed plan.
